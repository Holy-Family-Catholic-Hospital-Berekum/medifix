# HFCH Maintenance App - User Quick Reference Guide

## 👥 FOR EACH USER ROLE

---

## 👨‍💼 ADMIN - Dashboard Workflow

### Main Dashboard (Home)

- **Left Tab: "Incoming Reports"** - All new reports from staff
  - Click any report to view details
  - Click "Approve" to approve (optionally add notes)
  - Click "Deny" to reject with required reason/note

- **Right Tab: "Pending Confirmation"** - Awaiting your cost confirmation
  - Review cost & description entered by Estate Manager
  - Click "Confirm Cost" (optionally add notes for Estate)
  - Notes appear in Estate Manager's alerts

### Navigation

- **Assigned** - All reports currently assigned to workers (read-only)
- **Completed** - All completed reports (can view feedback)
- **Overdue** - Reports past due date
- **Alerts** 📢 - See all notes/messages for you

### Key Actions

1. Review incoming reports daily
2. Approve reports to move them to Estate Manager
3. Confirm costs to allow work assignment
4. Monitor completion status

---

## 🏢 ESTATE MANAGER - Dashboard Workflow

### Main Dashboard (Home)

- **Left Tab: "Approved Reports"** - Reports approved by Admin
  - Click any report to view details
  - Enter estimated cost amount
  - Enter cost description
  - Click "Submit Cost for Confirmation"
  - Status changes to "Pending"

- **Right Tab: "Confirmed Reports"** - Admin confirmed the cost
  - Click to open report details
  - Enter Worker ID to assign
  - Click "Assign Worker"
  - After assignment, enter detailed work instructions
  - Click "Save Instructions"
  - Instructions will appear in Worker's alerts

### Navigation

- **Assigned** - All reports assigned to workers (monitor progress)
- **Completed** - All completed reports
- **Overdue** - Reports past due date
- **Alerts** 📢 - See messages from Admin and others

### Key Actions

1. Add costs and descriptions to approved reports
2. Assign work to registered workers
3. Provide detailed instructions for workers
4. Generate Registration IDs for new workers
5. Download evidence/PDF for funding requests

### 📥 Generate Registration IDs

- Click "Generate Registration ID" button
- Select "staff" or "worker" when prompted
- Share the generated ID with the new person to register

## 👷 WORKER - Dashboard Workflow

### Main Dashboard (Home)

- **All Reports: "Assigned to You"**
  - View all work assigned to you
  - Click any report to view full details
  - Read work instructions (in alerts)
  - See sender contact info and location
  - When ready, click "Mark Work as Completed"

### Navigation

- **Completed** - All work you've completed
- **Overdue** - Work past due date
- **Alerts** 📢 - See work instructions and feedback

### Key Actions

1. Check dashboard daily for new assignments
2. Read work instructions carefully
3. Go to location and complete the work
4. Mark work as complete when finished
5. Check feedback from work you've completed

## 📝 STAFF - Dashboard Workflow

### Main Dashboard

- Custom dashboard for your submissions
- View status of all your submitted reports

### Report Details

- See if report is approved, pending, assigned, or completed
- Once marked "Completed", can submit feedback
- Click "Submit Feedback" button
- Your feedback will go to Admin, Estate Manager, and the Worker

### Alerts 📢

- See notes from Admin (approvals/denials)
- Get notified when your report is approved/assigned/completed

### Key Actions

1. Create new reports using "Create Report" button
2. Track status of your submitted reports
3. Submit feedback on completed work
4. Review messages from Admin

## 🔔 ALERTS SYSTEM

### Where to Find Alerts

- **Alerts Button**: 📢 Button on every page (bottom right on mobile, top right on desktop)
- Shows count of unread alerts
- Click to open alert panel

### What You'll See in Alerts

- **From**: Who sent the message
- **Role**: What role sent it (admin, estate, worker, feedback)
- **Date**: When the message was sent
- **Content**: The actual message

### Common Alert Messages

- **Admin denies report**: "Report denied - [reason]"
- **Admin approves report**: "Report approved" or with notes
- **Estate adds cost**: "Cost added - $X for [description]"
- **Worker assigned**: "You have been assigned a task"
- **Work instructions**: "Instructions: [detailed instructions]"
- **Work completed**: "Your work has been completed"
- **Feedback received**: "[Feedback from staff]"

## 📊 REPORT STATUS MEANINGS

| Status        | Meaning                          | What Happens Next             |
| ------------- | -------------------------------- | ----------------------------- |
| **incoming**  | Just created by staff            | Admin reviews                 |
| **approved**  | Admin approved                   | Estate Manager adds cost      |
| **denied**    | Admin rejected                   | Staff gets note, can resubmit |
| **pending**   | Awaiting Admin cost confirmation | Admin confirms cost info      |
| **confirmed** | Cost confirmed, ready to work    | Estate assigns to worker      |
| **assigned**  | Assigned to specific worker      | Worker completes task         |
| **completed** | Work is done                     | Staff can submit feedback     |

## 🎯 COMPLETE WORKFLOW EXAMPLE

### Day 1 - Staff submits issue

1. Staff creates maintenance report
2. Report status: **incoming**
3. Admin receives in "Incoming Reports"

### Day 2 - Admin reviews

1. Admin views report details
2. Admin clicks "Approve"
3. Report status: **approved**
4. Estate Manager receives in "Approved Reports"

### Day 3 - Estate adds cost estimate

1. Estate Manager opens report
2. Enters cost: "$500"
3. Enters description: "Parts and labor"
4. Clicks "Submit Cost for Confirmation"
5. Report status: **pending**
6. Admin receives in "Pending Confirmation"

### Day 4 - Admin confirms cost

1. Admin reviews cost
2. Adds note: "Approved, budget available"
3. Clicks "Confirm Cost"
4. Report status: **confirmed**
5. Estate Manager receives in "Confirmed Reports"

### Day 5 - Estate assigns worker

1. Estate Manager selects worker
2. Enters instructions: "Fix leaky faucet in Building A, Room 205"
3. Assigns worker
4. Report status: **assigned**
5. Worker receives notification

### Day 6 - Worker completes work

1. Worker sees report in "Assigned to You"
2. Worker goes to location
3. Completes the maintenance
4. Clicks "Mark Work as Completed"
5. Report status: **completed**

### Day 7 - Staff provides feedback

1. Staff sees report now shows completed
2. Clicks "Submit Feedback" button
3. Enters: "Great job, works perfectly!"
4. Feedback saved

## ❓ COMMON QUESTIONS

**Q: Can I edit a report after submitting?**
A: No, reports are finalized once submitted. Contact Admin if changes needed.

**Q: What if work isn't complete on time?**
A: Report will appear in "Overdue" tab. Continue work and mark complete when done.

**Q: Can I see reports from other staff members?**
A: No, each role only sees relevant reports.

**Q: How do I get a Registration ID?**
A: Contact your Estate Manager or Admin to generate one.

**Q: What if I forget my password?**
A: Use the password reset option on the login page.

## ⚡ TIPS & BEST PRACTICES

1. **Check Alerts Daily**: Messages from other team members appear here
2. **Provide Clear Instructions**: Workers rely on detailed instructions
3. **Complete Assignments Promptly**: Helps keep projects moving
4. **Review Feedback**: Use feedback to improve future work
5. **Download Evidence Early**: Estate Managers should save PDFs for funding
6. **Communicate Issues**: Use notes feature to share concerns
